# Plaud NotePin — data architecture research

Researched: 2026-11-03.

Evidence: public source and documentation inspection only. No hardware, authenticated service, model-quality, security, or runtime validation was performed. Implementation claims describe inspected code, not confirmed production deployment. Branch links may change.

- **Product scope:** The requested URL redirects to https://www.plaud.ai/products/plaud-notepin . It documents 64 GB local recording storage, up to 20 hours continuous recording, speaker-labelled transcription, multimodal additions (text/images/highlights), structured summaries and Ask Plaud. These are vendor product claims; the fetched listing shows Out of Stock, not a shutdown notice.
- **Concrete artifacts/access:** Consumer MCP documents `list_files`, `get_file`, `get_note`, `get_transcript`. File fields: `id`, `name`, ISO-8601 `created_at`/`start_at`, `duration` in milliseconds and `serial_number`. `get_file` additionally returns `presigned_url` (24-hour audio download), `source_list` (timestamped speaker-labelled transcript segments), and `note_list` (Markdown AI notes). `get_note` covers summaries/action items/key topics. The public page does not specify the complete nested `source_list` schema. Source: https://docs.plaud.ai/plaud-mcp-cli/mcp .
- **Retrieval:** MCP `list_files.query` is specifically case-insensitive keyword matching on recording **name**, with `date_from`/`date_to` and pagination (pagination ignored when filters are set). Do not describe this documented tool as full-transcript vector search. Ask Plaud is a broader product capability; its index/ranking/storage internals are undisclosed. OAuth authorizes MCP access; HTTP clients route recording data through a US-hosted Plaud MCP server, which the docs say retains it only for the request. Local MCP installation is not proof of offline/local AI.
- **Separate Embedded API, not an unrestricted consumer ASR endpoint:** Partner developer credentials (`client_id`, `api_key`) and Embedded SDK device binding are prerequisites. Upload audio to a publicly accessible URL, POST `/developer/api/open/partner/ai/transcriptions/`, then poll the task ID until `SUCCESS`. Options include language/model (`plaud-fast-whisper` in the example), `vad.decode_silence`, `diarization.enabled`. Result example: `{transcription_id,status,data:{text,language,duration,segments:[{start:0,end:4.2,text:"...",speaker:"Speaker 1"}]}}`. The page does not explicitly state units for these segment numbers; do not confuse them with MCP's explicitly millisecond duration. Recordings over five hours should be chunked. Default cloud region is US, alternate regions by sales arrangement. Source: https://docs.plaud.ai/plaud-embedded/transcription-api-overview .
- **Exports, version caveat:** Verified guide for app v3.30.x or earlier lists audio MP3/WAV (Web MP3 only), transcript TXT/SRT/DOCX/PDF, summary TXT/Markdown/DOCX/PDF, mind map PNG/Markdown. Transcript export offers timestamps and speaker labels, including assigned names; exports are normally one file at a time, with MCP suggested for bulk retrieval. Source: https://support.plaud.ai/hc/en-us/articles/50835453223705-Export-recordings-transcripts-and-summaries . Its linked v4 guide exists but returned HTTP 403 through both short and full URLs, so do not present the old table as verified v4 behavior: https://support.plaud.ai/hc/en-us/articles/63429911054617-Export-transcripts-notes-and-audio-for-v4-0-x-or-later .
- **Cloud/privacy distinction:** The September 2026 support article says, with Private Cloud Sync off, recordings/transcripts/summaries are deleted from Plaud servers immediately **after processing**; with sync on they persist until explicit deletion. Thus sync-off is not no-cloud processing. Source: https://support.plaud.ai/hc/en-us/articles/49922008621337-How-is-my-data-handled-after-transcription . The legacy sync guide additionally says disabling sync does not delete previously uploaded data and Team workspaces cannot disable it: https://support.plaud.ai/hc/en-us/articles/50835508850841-Private-Cloud-Sync .
- **New-policy nuance relevant to memory/artifacts:** https://web.plaud.ai/privacy explicitly describes segmented/numbered transcripts for source citations linking generated outputs to original audio; agent conversations/files stored in cloud and relevant content sent to third-party LLM providers; optional Memory extracts key information from historical conversations/notes/transcripts into editable/deletable memory items and profiles. This is evidence for memory items and provenance-linked artifacts, **not a temporal graph**. It also describes voiceprints for enabled speaker recognition, including cross-recording recognition of named speakers with consent. It prohibits using content to train models without explicit informed advance consent, and says providers have limited task/security/compliance retention. Crucially this policy applies immediately to accounts created on/after October 20, 2026, but only from November 21, 2026 for older accounts. Do not silently apply it retroactively or conflate agent-chat retention with the older transcription-only deletion promise.
