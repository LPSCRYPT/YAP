# Limitless — data architecture research

Researched: 2026-11-03.

Evidence: public source and documentation inspection only. No hardware, authenticated service, model-quality, security, or runtime validation was performed. Implementation claims describe inspected code, not confirmed production deployment. Branch links may change.

- **Not a blanket shutdown:** https://www.limitless.ai/ states new Pendant sales stopped **December 5, 2025**; existing Pendant customers receive free Unlimited and support **throughout 2026**. Service stopped December 5, 2025 in Brazil, China, EU, Israel, South Korea, Turkey and UK; those users had until **December 19, 2025** to export before account/data deletion. Rewind's final update disables screen/audio capture beginning **December 19, 2025**. Desktop/Web no longer record, but previously recorded meetings remain accessible throughout 2026. These dates do **not** establish a worldwide API shutdown or a guaranteed December 31 shutdown; the announcement is a support commitment, not proof of present uptime.
- **Historical integration and current documentation:** Official examples still demonstrate API-key access and Markdown export: https://github.com/limitless-ai-inc/limitless-api-examples . Currently published docs at https://www.limitless.ai/developers describe `X-API-Key`, Pendant pairing as prerequisite, beta limited to Pendant data, and 180 requests/minute/key. They expose GET list/detail and DELETE for Lifelogs/chats, GET audio, and MCP at `https://api.limitless.ai/mcp`. Public documentation remaining available is not an authenticated functionality test, and legacy onboarding wording conflicts with closed new sales.
- **Schema:** A Lifelog has `id,title,markdown,startTime,endTime,isStarred,updatedAt,contents[]`. Content nodes have `type` (`heading1|heading2|blockquote`), `content`, absolute ISO-8601 `startTime/endTime`, `startOffsetMs/endOffsetMs`, nested `children`, `speakerName`, and `speakerIdentifier` (`"user"|null`). This is a time-bounded hierarchical document representation. `speakerIdentifier` is not a general persistent person ID; generic names do not establish cross-recording identity resolution. `includeContents` defaults false; request it for detailed segments. Source: https://www.limitless.ai/developers#get-lifelogs .
- **Retrieval:** GET `/v1/lifelogs` supports date/range/timezone, order, star filter, cursor and maximum 10 results. `search` is explicitly **hybrid keyword plus semantic search**, supporting natural-language and Boolean keyword queries. Search disables cursor pagination. This supports saying hybrid retrieval, but not naming a vector database, embedding model, graph or temporal-query engine. MCP provides search/question access over Lifelogs. Source: https://www.limitless.ai/developers .
- **Outputs/processing:** Documentation and policy support audio → text transcription → summarization, with resulting Markdown headings and speaker transcript blocks. The exact proprietary grouping/summary algorithm is not public. Chat export adds `id,summary,createdAt,startedAt,messages,visibility`; messages include text, timestamps, user role/name, tool calls/results, and returned-entry IDs/titles, so retrieval traces are partly available. Official `python/summarize_day.py` fetches up to ten lifelogs and sends them to OpenAI `gpt-4o-mini` for a streamed summary: https://github.com/limitless-ai-inc/limitless-api-examples/blob/main/python/summarize_day.py . This is an **example application**, not proof Limitless internally used that model/pipeline.
- **Audio/export:** `/v1/download-audio` returns original Ogg Opus binary using Unix-millisecond `startMs/endMs`; maximum two hours/request, Pendant only. Account Data Exports includes entire Lifelog/meeting transcript history and chats, optionally audio, with async email notification; guidance recommends 1–2 month ranges for large exports. Source: https://help.limitless.ai/en/articles/13004987-how-to-download-your-limitless-transcripts-and-account-info . That guide does not specify the complete exported archive schema.
- **Current privacy is not the old marketing story:** https://www.limitless.ai/privacy describes encrypted device transfers/TLS/storage and configurable audio retention (day/week/month/year/forever), plus notice/consent obligations. But the actual policy, updated **December 5, 2025**, explicitly permits use to **train/develop/improve AI/ML/LLMs**, cloud audio storage, third-party AI transcription/summarization, affiliate sharing, and US hosting: https://www.limitless.ai/privacy-policy . Do not assert current zero-training, purely local processing or provider-inaccessible end-to-end encryption based on older descriptions. Policy permission is not proof a particular user's data was actually used in training.
